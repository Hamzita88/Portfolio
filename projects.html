Sobre el proyecto

Polaris Insights

Dashboard de marketing que reúne indicadores, canales y campañas para explorar el rendimiento desde una misma interfaz.

Next.js 16 React 19 Supabase Tailwind CSS
Qué incluye
  • KPIs: visión general de los indicadores de marketing.
  • Canales: análisis del rendimiento por canal.
  • Campañas: seguimiento de las acciones de marketing.

Acceso restringido: la aplicación requiere una cuenta por invitación. No es una demo pública.

Caso de estudio / Aprendizaje

Polaris: un proyecto para aprender

Objetivo

Explorar el desarrollo asistido por IA y aprender Next.js, un framework de React, mediante una aplicación de marketing y CRM.

Mi aportación

Desarrollé Polaris de forma individual, con asistencia de IA, como proyecto personal de aprendizaje.

Aprendizaje y método

Aprendí sobre SDD y TDD con Gentleman Programming. El repositorio recoge especificaciones y tareas con un enfoque de pruebas primero.

Un comportamiento bajo prueba

Las pruebas cubren el cambio de etapa de un lead y la generación de su actividad. También verifican que mantener la misma etapa no cambie el lead ni genere actividad.
